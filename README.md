# PatientTrac Limited

Corporate website for PatientTrac Limited, the London-based international
financial consulting and corporate development firm.

## Content

- Company overview and international reach
- Corporate financings
- Mergers and acquisitions
- Public entity development
- Global market access
- London office and legal contact information

## Development

Requirements: Node.js 22.13 or later.

```bash
npm ci
npm run dev
```

## Netlify

`netlify.toml` contains the production build settings. Connect the repository
to Netlify and deploy from the repository's default branch. The intended custom
domain is `patienttracltd.com`.
